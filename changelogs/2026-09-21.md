# 2026-09-21

## 00:21 — 縮小到系統匣改回隱藏主窗，避免再開卡住

### 總體
打叉「縮小到系統匣」不再銷毀 Photino 主窗。關窗會在執行緒留下 WM_QUIT，再開時第二次 WaitForClose 立刻結束、視窗沒有訊息幫浦，錄影中關窗再開就會卡住。改回隱藏，第一次 WaitForClose 繼續跑。

### 檔案
- `Backend/App/Program.cs`：Minimize 改走 HideApplicationWindow 並取消關閉，不再 Window = null
- `changelogs/2026-09-21.md`：本筆

### 更動
- 縮小到系統匣：主窗隱藏、行程與錄影繼續，極簡監控可留著或之後再開
- 托盤／再執行 Segra 還原現有主窗，不再 LoadFrontend 建第二個 Photino 窗
- 關閉即結束程式的路徑沒改
- 托盤時主窗 WebView 不再卸載（Photino.NET 沒有 PhotinoApplication，銷毀再開會卡住）

## 00:30 — 捷徑再開改走與系統匣相同的還原

### 總體
縮小到系統匣後，從工作列或桌面捷徑再開打不開。第二個行程只送 pipe SHOW_WINDOW，舊路徑 SetMinimized 無法解除 SW_HIDE。改成跟托盤一樣呼叫 ShowApplicationWindow。

### 檔案
- `Backend/App/Program.cs`：pipe 在 Window 已存在時改呼叫 ShowApplicationWindow
- `changelogs/2026-09-21.md`：追加本筆

### 更動

- 尚未建窗（開機先縮到托盤）仍只 Set ShowWindowEvent
- 系統匣開啟路徑沒改
